# NSEC01 — Node.js 보안 업데이트와 호환성 검증 (2026-10-24, 판정 대기)

- 시작 기준: 최신 origin/main bcec1df에서 chore/node-security-20261024 및 별도 worktree 생성함. 원래 폴더 삭제 3건과 AI 개발 worktree의 미승인 AIR01 6파일 보존함. 현재 요청은 영향 조사 후 계획 수립·업데이트 진행이며 기존 저장소의 최종 통과 조건은 유지함.
- 문제·요청: PC Node24.14.0·운영 CI Node20.20.2를 보안 수정 버전으로 전환하되 기존 글쓰기·빌드·OAuth 도구의 영향을 먼저 확인할 필요 있음. [계획](../plan/Node.js-보안-업데이트-개발계획.md)과 [실제 검증·설치 예외](../guide/Node.js-보안-업데이트-검증.md)에 조사·대응·검사·한계 기록함.
- Red: 버전 파일과 engines 제한이 없는 기존 설정에서 보안 정책 새 검사 2개 실패 확인함. 설치 네트워크나 서버 미실행을 Red로 삼지 않음.
- 수정: 공식 24.22.1 ZIP 해시 검증 후 격리 검사함. 공통 .node-version·CI 두 작업 참조·engines >=24.22.1 <25·engine-strict·lock 루트 메타데이터·개발 안내 반영함. 의존성 그래프는 JSON 대조로 불변 확인함. H02는 러너 대기 포함 오측정을 실제 브라우저 클릭→준비 측정으로 보완했으며 기준 2초/3초와 그래프 조작 검증 유지함. 앱 src·OAuth 권한·배포 트리거 변경 없음.
- 자동 검사: 기존 Node 107개·타입79파일 오류/경고0·힌트5·빌드 통과함. 새 Node로 clean install·109개·타입80파일 오류/경고0·힌트5 통과함. 실제 구형 설치 거절/신규 허용 확인함. 전후 비교 빌드40파일 동일함. preview7·OAuth33·초안15·H01 4 통과, H02 3사례×3회=9 통과·skip0·그래프1304~1528.1ms 확인함. AI worktree의 기존616개도 새 Node에서 통과함. 실제 설치 Node+기존 npm11.12.1로 clean install·109개 재확인함. MSI exit0·레지스트리24.22.1·node.exe가 검증 ZIP과 동일·정상 Brotli 왕복 확인함. 전역 CLI5종 시작 확인함.
- 실패와 조치: 동시 비교 빌드 회차 초안15개 실패 뒤 구형/신규 단독 실행 각15개 통과했으며 최초 원인은 미확정임. 최초 빌드해시1파일 차이는 재비교40파일 일치했으며 원인미확정임. H02의 러너2029/2018/2042ms 대 브라우저약1576ms 차이 계측 뒤 테스트 측정만 보완함. PowerShell 빈 키 JSON 처리·npm stderr 경고 오인·임시 진단 cwd 오류는 검증 도구 문제로 분리해 바로잡음. 테스트 삭제·skip·기준 완화 없음.
- PC 설치 예외: 외부 파일 쓰기는 실행 도구 승인 후 공식 서명/해시 MSI로 수행함. 새 MSI에 Restart Manager 비활성 옵션을 전달했지만 구버전 제거 세션에서 앱 종료·재시작 기록 확인함. 강제 종료 없이 적용한다던 사전 안내를 충족하지 못해 사용자에게 즉시 알림. 설치 전 관찰 PID18개 중17개가 설치 후 없었으나 전부 MSI 때문이라고 단정하지 않음. 앱별 미저장 상태·기존 명령 복구는 확인하지 못했으며 사용 중이던 CLI·서버 재시작 필요를 안내함. 자동 재부팅·OS 정책 변경·Stop-Process 실행 없음.
- 남은 제약: 현재 커밋·push·원격 CI·main 반영 전임. Node 설치 완료와 운영 CI 적용 완료를 구분함. 관리형 Cloudflare/Actions 내부 런타임·실제 운영 계정·타 PC 프로젝트 전체의 안전성은 인증하지 않음. 구체적 변경의 통과 후에만 현행 approve→커밋→개발 push 진행함.
- 마감 확인: 변경13파일 UTF-8·대체문자 없음·Markdown 로컬 링크66개 확인함. 원래 폴더 삭제3건과 AI worktree의 기존 스테이징6파일 유지 확인함. 검토용 계획·검증 보고를 기본 편집기로 열고 이번13파일만 스테이징 대상으로 정함. 사용자에게 반복 자동 검사나 git diff 확인을 요청하지 않으며 앱 작업 상태·재시작 필요와 실제 원격 CI 미검증 범위를 설명함.
