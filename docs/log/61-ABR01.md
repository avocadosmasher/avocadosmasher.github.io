- 문제·요청: 다른 세션이나 AI가 동일 콘텐츠를 중복 생성하거나, 생성 요청을 수정으로 바꾸어 덮어쓸 수 있다. 승인받은 계획의 ABR01에 따라 확정 입력·대상 식별·신규/수정/재실행/충돌·두 작성 경로의 승인 기준을 공통 규약으로 정리한다.
- Red: 문서 작업이므로 억지 실패 테스트를 만들지 않았다. 완료 기준은 각 작업 상태의 행동과 현재 코드의 보장 범위를 구별하고, 입력·현재 상태·예상 결과를 예시로 설명하는 것이다.
- 수정: `docs/guide/AI-콘텐츠-작업규약.md`를 추가했다. 원래 경로·ID·생략 필드 보존, 같은 내용의 변경 없음, 다른 내용·모호한 대상·동시 수정의 충돌, 웹 미지원 작업 인계와 저장·발행 승인 경계를 기록했다. 웹 신규 카드에는 ID 지정란이 없음을 확인해 저장 결과의 실제 ID 인계와 특정 ID 요청의 저장소 인계를 구분하고 선택 근거를 결정 기록에 남겼다. ABP01 통과·push 증거를 STATUS·메뉴판·계획·결정 기록에 반영하고, 당시 판정 대기로 작성된 ABP01 로그 원문은 보존했다.
- 사용자 추가 요청: 확인이 필요한 파일은 에이전트가 직접 열도록 요청받아 AGENTS의 수동 검증 준비 항목과 STATUS 안내에 기록했다. 현재 검토 대상인 규약 파일도 기본 연결 프로그램으로 연다. 이번 ABR01 판정 범위에 이 준비 절차 변경을 함께 포함한다.
