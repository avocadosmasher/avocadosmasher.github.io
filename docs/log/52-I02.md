## 3. 비밀값·fixture·디버그 설정 점검

- **비밀값**: 추적 파일 전체에서 `client_secret`/토큰 패턴을 검색했다. 실제 값은 없고 변수명·테스트용 더미(`test-secret-never-public` 등)뿐이다. `.dev.vars`, `.env`는 `.gitignore`에 있고 추적되지 않는다. 운영 빌드 산출물(`dist/`)에도 비밀값 패턴이 없다. `tests/unit/oauth.test.ts`는 리다이렉트 URL과 오류 HTML에 Secret이 섞이지 않는지를 직접 단언한다.
- **fixture 격리**: `scripts/fragment-fixture.mjs`는 `.fragment-test/fixture-content`에만 쓰고 운영 콘텐츠를 읽지도 쓰지도 않는다. H05-FIX 이후 규칙대로 E2E는 빌드 산출물에서 데이터를 읽는다. `tests/admin/*`만 `src/content/fragments`를 만지는데, **변경 전/후를 비교해 그대로인지 단언하는 읽기 전용 가드**와 격리 폴더 밖 경로 요청이 거부되는지 확인하는 용도다. 운영 카드 3개(`ept.md`, `gpa.md`, `fragment-feb11db2…md`)에 테스트가 쓰기를 하지 않는다.
- **디버그 설정**: 우리 코드의 `console.log`는 전부 Node 개발 스크립트(`scripts/*.mjs`)에만 있고 브라우저로 나가는 코드에는 없다. `127.0.0.1:8082` 로컬 proxy 경로는 `src/scripts/fragment-admin.ts:26`에서 호스트명이 `localhost`/`127.0.0.1`일 때만 동작하도록 막혀 있고, `import.meta.env.DEV && FRAGMENT_CMS_LOCAL=1`이어야 켜진다. 운영 빌드의 `/admin/`은 backend 설정이 비어 있어 CMS가 초기화되지 않으며 `noindex`다(`tests/e2e/admin-disabled.spec.ts`가 프록시·GitHub 요청이 없음을 단언).

## 4. 미해결 문제와 영향

1. **`/admin/` Decap 번들 5.0MB이 운영 산출물에 포함된다.** 기능은 꺼져 있고(백엔드 설정 없음, noindex) 보안 영향은 확인되지 않았지만, 배포마다 5MB가 GitHub Pages로 나간다. 실사용 진입점이 아니므로 **후속 과제**로 남긴다(제거하려면 `public/admin/vendor`와 `src/pages/admin/`, `tests/admin/*`를 함께 정리해야 한다).
2. **`npm run test:admin`은 CI 게이트 밖이다.** 로컬 proxy가 필요해 Actions에서 돌지 않는다. Decap 경로가 깨져도 CI는 잡지 못한다. 위 1번을 정리하면 함께 없어진다.
3. **실제 단말·스크린리더 검증 없음(H01).** 390px/1280px 에뮬레이션과 키보드 흐름만 자동화했다.
4. **성능 목표는 기기 의존.** 그래프 2초는 개발 PC 목표, CI 한도는 3초다(H02-CI). 러너가 느려지면 다시 조정이 필요하다.
5. **로컬에서 운영 OAuth 로그인 불가.** Worker가 운영 도메인만 허용해서, 운영 인증 회귀는 배포 사이트에서 사람이 확인해야 한다. 자동 검사는 mock 경로만 덮는다.
6. **GitHub API 한도.** 익명 조회 60회/시간(D08에서 로그인 시 토큰 사용으로 완화), 배포 반영까지 3~4분. 상세는 운영 가이드 4장.
7. **초안은 공개 저장소의 `fragments-draft`에 있다.** 발행 전 내용도 저장소를 보면 읽힌다. 계획 단계에서 받아들인 제약이다.
8. **기록 표기 정정**: J01은 `322ae0a`로 커밋되어 있는데 `STATUS.md`와 메뉴판은 "판정 대기"로 남아 있었다. 이번에 커밋 해시와 함께 상태를 맞췄다. 계획서의 G04-UI·G05/G06-UI·G08-UI·H01·H02·H04 행도 "수동 판정 대기"로 적혀 있으나, 이 흐름들은 2026-09-24 H05 운영 확인에 포함되었다. 행 문구는 당시 기록이므로 고치지 않고, I03 보고서에서 H05 확인이 이들을 포함한다는 점을 명시한다.
