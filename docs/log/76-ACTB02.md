# ACTB02: 기존 글 부분 수정·기준 변경 차단 (2026-10-19, 통과)

- 판정·저장: 사용자 명시적 통과 후 기존 승인 명령으로 승인된 트리를 기록하고 `736c11a` 커밋·개발 브랜치 push 완료함. 파일 변경 없이 통과받은 내용을 그대로 저장한 뒤 ACTF01 진행함.

- 시작 기준: ACTB01 명시적 통과 후 `7490a2c` 커밋·개발 브랜치 push 완료 확인함. 승인된 트리를 그대로 저장한 다음 이번 변경을 시작함. 원래 폴더의 스테이징 삭제 3건은 별도 보존함.
- 문제·요청: 제목만 수정해도 원문 전체 재직렬화로 주석·줄바꿈·필드가 달라지거나 오래된 본문을 덮어쓸 수 있어 정확한 값 범위 수정과 기준 재확인이 필요함. 사용자 요청에 따라 자동 검증 가능한 CLI 직접 실행을 요구하지 않도록 AGENTS·계획에도 명시함.
- Red: 현재 CLI가 기존 글 수정 계획을 거절하는 상태에서 원문 보존·계획 후 본문 변경 차단의 기대 결과 2건 실패 확인함. 요청 값 범위 편집·어댑터·CLI 연결 후 Green 확인함. 배열 값 범위 밖 들여쓰기는 보존된다는 점을 기대 원문에 반영하고, 잘못된 전방 YAML 별칭 fixture를 유효한 순서로 정정함. 기존 경로 차단의 오류 코드는 path.symlink 계약을 유지함.
- 수정: 기존 글의 요청 값·명시한 본문만 교체함. 미요청 원문·날짜·초안·태그·자산·경로·BOM·CRLF·주석 보존함. 기본값과 같은 생략 필드는 삽입하지 않음. 추가 자산은 새 경로만 허용하고 글이 같으면 mtime도 보존함. 실제 후보로 계획을 다시 만들어 변조를 거절함. 적용 전 원문 지문과 정책을 재검사하고 임시 파일 완성 후 지문을 다시 확인해 rename으로 교체함. 기록 없는 동일 결과는 쓰기·새 기록 0건이며, 완료 기록이 있으면 실제 전체 파일 지문을 확인함. 수정 전후 원문을 CLI에 구별해 표시함.
- 자동 검사: 신규 통합 34개 포함 전체 390개·27파일 통과함. 초기 타입 표기 오류 2건을 보완하고 최종 Astro 검사 107파일 오류 0/경고 0/기존 힌트 5 확인함. 일반 빌드 11페이지·18이미지 성공함. 별도 격리 CLI 생성→수정→각 재실행에서 바이트·파일 목록·mtime 보존과 실제 Astro 제목·본문·SVG 산출물·검색 제목 검증함. 현재 수집 글 13개·Fragment 3개 검사 오류 0·기존 예외 4·미사용 예외 0 확인함. Graft 소스 90개 갱신함.
- 사용자 확인: 화면·외부 계정 흐름 변경이 없으며 파일·종료 코드로 검증 가능한 동작이므로 직접 실행할 항목 없음. 동작·예시·한계를 설명한 글 생성·부분 수정 가이드를 기본 앱으로 열었음. 기존 AGENTS의 현재 변경 통과 판정은 유지하며 판정 전 승인·커밋·push하지 않음.
- 마감 확인: 이번 변경 파일 19개·상대 링크 127개·한국어 문구·인코딩·ACTB02 메뉴판 단일 항목 확인함. 작업 폴더의 운영 콘텐츠·CATEGORIES·스키마·기존 예외·승인 훅·CI·배포·패키지와 잠금 파일 변경 없음 확인함. 원래 폴더의 스테이징 삭제 3건 보존함. 기존 CLI 동작 회귀와 격리 실제 빌드로 검증하며 화면 변화가 없어 브라우저 E2E는 반복하지 않음. 이번 작업의 파일 19개만 스테이징 대상으로 지정함.
- 남은 제약: 마지막 지문 확인과 rename 사이 외부 쓰기의 원자적 차단·도구 간 잠금·다중 파일 원자성·중단 복구·실패 주입은 ACTS01 범위임. 수정 대상에 앵커가 포함되거나 흐름 매핑의 메타데이터를 바꾸는 요청은 추측하지 않고 거절함. 다른 대상 어댑터·Hook/CI 저장 차단은 후속 작업임. 운영 콘텐츠·실제 글의 경로·원문·예외 목록·스키마·승인 훅·배포 설정은 변경하지 않음.
