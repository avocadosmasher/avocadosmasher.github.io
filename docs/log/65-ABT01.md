- 자동 검사: 템플릿 frontmatter 2개의 YAML 문법·중복 키·현행 필드·배열·새 글 draft:true·명시적 날짜/ID 표시를 검사했다. 치환 표시 14개가 모두 안내에 있고 템플릿이 두 콘텐츠 수집 루트 밖에 있음을 확인했다. 문서 링크 17개와 ABT01 로그·메뉴판 각 1건, ABI02 통과 증거 및 문구 검사 통과. `npm run build` 성공(11페이지), 산출물 HTML 11개에 신규 템플릿 날짜/ID 표시가 없고 기존 공개 예제 페이지가 유지됨을 확인했다. 기존 글 코드 블록의 plain_text·plain-text 언어명은 plaintext로 대체하는 안내가 있었으며 이번에 운영 본문은 수정하지 않았다. `git diff --check` 및 `git diff --cached --check` 통과. 스테이징은 이번 파일 8개뿐이며 미스테이징 변경은 없다.
