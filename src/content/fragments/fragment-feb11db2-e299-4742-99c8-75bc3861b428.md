핵심 기술
1. **PagedAttention**: KV 캐시를 운영체제의 메모리 페이지처럼 작은 블록으로 나눠 관리해 GPU 메모리 낭비를 줄임
2. **Continuous batching**: 끝난 요청 자리에 새 요청을 바로 끼워 넣어 처리량을 높임
3. **OpenAI 호환 API 서버**: 기존 OpenAI 클라이언트 코드로 그대로 호출할 수 있음

함께 기억할 것: vLLM은 모델을 직접 실행하는 쪽(서빙 엔진)이고, LiteLLM·LLM Gateway는 요청을 어디로 보낼지 정하는 쪽임.
